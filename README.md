# Vite + React JavaScript Template

A modern React application template using Vite as the build tool.

## Features

- ⚡️ [Vite](https://vitejs.dev/) - Lightning fast build tool
- ⚛️ [React 18](https://react.dev/) - A JavaScript library for building user interfaces
- 🧪 [Vitest](https://vitest.dev/) + [Testing Library](https://testing-library.com/) - Unit testing setup
- 📦 Modern JavaScript (ES modules)

## Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:5173`

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm test` - Run tests with Vitest

## Testing

This template includes a basic testing setup with:
- Vitest as the test runner
- React Testing Library for component testing
- Jest DOM matchers for enhanced assertions

Run tests with:
```bash
npm test
```

## Deployment

Build the app for production:
```bash
npm run build
```

The built files will be in the `dist/` directory, ready to be deployed to any static hosting service.
